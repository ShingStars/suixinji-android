# 课程表导入：1.1.2

先在“我的 → 学期管理”设置目标学期的开学日期、教学周、全部节次钟点。导入课程沿用这些配置；节数或周数超出配置时需先修改学期。

## 教务网页

在“日历 → 课程表 → 导入课程 → 教务网页导入（多校）”填写学校完整 HTTPS 网址，点“打开”。支持校方统一认证跳转。本人输入账号密码和验证码，进入目标学期的完整课表后点“读取课表”。应用不保存密码，离开本次教务浏览器后清理网页会话。

如果显示多个页面，选择包含实际课表的页面；外层门户可能也含有布局表格。跨域框架会提供“先打开再读取”，进入后再次点读取。若系统动态页面没有表格，可打开学校打印课表页面或导出文件。

苏大旧入口 `http://xk.suda.edu.cn/` 可在确认明文传输风险后打开，许可只维持本次会话。其他 HTTP 学校入口通过系统浏览器打开，保存实际课表 HTML 后返回文件导入。应用不会忽略证书错误；校园网/VPN 可达性由手机网络决定。

## 可识别的文件结构

| 类型 | 识别范围 | 验证依据 |
|---|---|---|
| 旧正方/苏大 | Table1 或完整周表中的“周X第N节{第N周}” | 既有匿名苏大夹具及回归测试 |
| 新正方 | 课程 title、星期单元格 ID、教师/地点/节周标记 | 合成结构测试；未逐校在线验收 |
| 强智 | 七天表头、kbcontent、老师/教室/周次(节次)标记，明确的 `[01-02]节` | 合成结构测试；其他强智变种可能需适配 |
| 课程清单式 URP 等 | 含课程名、星期、周次、节次列，可含节数和合并单元格 | 合成结构测试；不包括新 URP 私有接口 |
| CSV | 应用提供的七列模板 | 引号、单双周、间断周与范围验证 |

支持某类结构不表示该厂商所有版本或所有学校均可用。未识别页面、空结果、缺少明确周次/节次会报错；不会默认填成全学期或推算节次。

预览时核对课程、星期、节次、周次、教师、教室，默认追加并去重。替换需再次确认，旧课程进入回收站。CSV/HTML 支持 UTF-8 和 GB18030，文件上限 2 MB；不支持 APK、PDF、图片 OCR、直接读取 xlsx 或 WakeUp 私有口令。
